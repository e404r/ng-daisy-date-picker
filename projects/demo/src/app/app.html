Quickstart Guide How to use

1. Install package & dependencies:
npm install ng-daisy-date-picker @angular/cdk date-fns
2. Include CDK overlay styles in styles.css:
@import "@angular/cdk/overlay-prebuilt.css";
3. Import & use in Standalone Component:
import { DaisyDatePickerComponent, DaisyRangePickerComponent } from 'ng-daisy-date-picker';
<daisy-date-picker [(ngModel)]="myDate" color="primary" size="md" />
<daisy-range-picker [(ngModel)]="myRange" [presets]="presets" />
